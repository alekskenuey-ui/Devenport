Опис

Ручний акумуляторний ліхтарик COBA CB-2506 з 5 кольорами світла

Ручний ліхтарик COBA CB-2506 — потужний портативний ліхтар для дому, автомобіля, риболовлі, кемпінгу, походів, охорони та аварійних ситуацій. Модель має міцний корпус з алюмінієвого сплаву, яскраве світло та кілька кольорових режимів для різних задач.

Ліхтарик оснащений світлодіодом TG WICK та підтримує біле, червоне, зелене, синє і жовте світло. Завдяки цьому його можна використовувати не тільки для звичайного освітлення, а й для сигнальних або спеціальних режимів. Також передбачений USB-вихід, що дозволяє використовувати ліхтарик як додаткове джерело живлення для заряджання гаджетів.
