Рюкзак для ноутбука з USB-портом, місткий міський рюкзак із поліестеру

Практичний та стильний рюкзак для ноутбука чудово підходить для навчання, роботи, поїздок і щоденного використання. Лаконічний сірий дизайн робить його універсальним варіантом для студентів, школярів та офісних працівників.
